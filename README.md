# Intermediate Project: Advertising Analytics

This project demonstrates data analysis skills using real-world advertising data from Google Ads and Facebook Ads.

## Project Overview

I combined advertising performance data from multiple sources and performed comprehensive analytics to understand campaign performance, ROI, and conversion patterns.

## Technologies Used

- **SQL** — Data integration, aggregation, and analysis
- **BigQuery** — Large-scale data queries and BI report preparation

## Project Components

### 1. SQL Analysis

Four SQL queries analyzing Facebook and Google Ads data:

- **Query 1.1** — Daily Spend Metrics (Average, Max, Min)
- **Query 1.2** — Return on Marketing Investment (ROMI) Analysis
- **Query 1.3** — Weekly Performance Analysis (Highest Value Week)
- **Query 1.4** — Campaign Growth Analysis (Monthly Comparison)

### 2. BigQuery Analysis

Three BigQuery tasks preparing data for BI reporting:

- **Task 2** — Data Preparation for BI Reports
- **Task 3** — Traffic Channel and Conversion Analysis by Date
- **Task 4** — Landing Page Conversion Comparison

## Key Skills Demonstrated

- Data integration using UNION/UNION ALL
- Complex aggregations and calculations
- Window functions for trend analysis
- ROMI and conversion rate calculations
- BI data preparation and optimization

## Data Sources

- Facebook Ads data (daily performance, ad sets, campaigns)
- Google Ads daily performance data
